Services

What I can build

Small websites, built properly, using only the tools the browser already understands.

SERVICE 1

Multi-page websites

Websites of several pages that share one design. A single stylesheet keeps every page looking the same, so a change to the colours in one file changes the whole site at once.

SERVICE 2

Simple online shops

A shop page with products, an add-to-cart button, quantity controls and a running total. Everything happens inside the browser, so there is no server to pay for.

SERVICE 3

Contact and comment forms

Forms that actually deliver. A form with no address behind it does nothing when you press send, so I connect mine to a service that forwards the message to a real inbox.

SERVICE 4

Mobile-friendly layouts

Pages that rearrange themselves on a small screen instead of forcing the reader to pinch and zoom. This is done with CSS Grid and a media query.

How I work

Three steps, in this order

STEP 1

Write the HTML first

Before any colours or fonts. If the page does not make sense with no styling at all, then the structure is wrong and styling will not save it.

STEP 2

Then the CSS

I choose the colours and fonts before I style anything, and I write them down. Then I style the page using only those choices.

STEP 3

JavaScript last

Only where the page genuinely needs to change while the visitor is looking at it. On this site, that is the shopping cart and nothing else.
